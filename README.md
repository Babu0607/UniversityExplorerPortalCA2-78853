# University Explorer Portal (CA2)

This is my CA2 project for the BSc in Science in Computing & Multimedia
module "Full Stack Development" at Dorset College Dublin.
It is a Blazor Web Application that implements an
API Mashup using public Countries and Universities APIs alongside
the Edutots Student Application API to manage university applications.

## What It Does
- University Explorer (API Mashup): Select a country to view its details, browse universities in that country, filter universities in real time, and view selected university details.
- Student Applications (CRUD): View submitted applications (`GET`), create new applications (`POST`), and edit existing applications (`PUT`).

## Tech Stack
- Framework: .NET (Blazor Server)
- Language: C#
- APIs: Countries API, Universities API, and `edutots.net` Student Application API
- Frontend: Bootstrap & Razor components

## How to run it locally
1. Clone the repo:
   ```bash
   git clone [https://github.com/Babu0607/UniversityExplorerPortalCA2-78853.git](https://github.com/Babu0607/UniversityExplorerPortalCA2-78853.git)
   ```
2. Navigate into the folder and run:
   ```bash
   cd UniversityExplorerPortalCA2-78853
   dotnet restore
   dotnet run
   ```
